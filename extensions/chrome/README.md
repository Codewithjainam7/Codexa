# Codexa Chrome & Chromium Extension

Deterministic AST Static Analysis, Vulnerability Auditing, and GitHub PR Review Companion.

## Features
- **GitHub PR Overlay**: Injects an inline "Codexa Audit" badge directly into GitHub pull requests and repository overview pages.
- **1-Click Audit**: Immediately sends repository URLs to the Codexa platform for deep AST scanning.
- **Security Sandbox Shortcut**: Quick access to the multi-language security playground.

## Installation in Chrome / Brave / Edge
1. Open `chrome://extensions` (or `edge://extensions`, `brave://extensions`).
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked**.
4. Select the `F:/Codexa/extensions/chrome` directory.
5. The Codexa icon will appear in your browser toolbar!
