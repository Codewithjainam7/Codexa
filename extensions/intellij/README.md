# Codexa IntelliJ IDEA Plugin

Deterministic AST static analysis and security gate integration for JetBrains IDEs (IntelliJ IDEA Ultimate & Community).

## Features
- Deep JavaParser AST inspections for SQLi, SSRF, Deserialization, and LLM prompt concatenations.
- Production readiness score card embedded in the IDE tool window.
- Seamless connection to the deployed Codexa cloud engine (`https://codexa-ye85.onrender.com`).
