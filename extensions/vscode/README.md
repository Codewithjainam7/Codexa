# Codexa VS Code Extension

Deterministic AST Security Analysis, OWASP Top 10 Guardrails, and 1-Click AI Fixes for Visual Studio Code.

## Features
- **Deterministic AST Scanning**: Instant feedback on SQL injections, command injections, deserialization flaws, and prompt injections.
- **OWASP LLM & API Guardrails**: Automated checks for direct prompt injection and BOPLA object binding.
- **IaC Auditing**: Dockerfile and Terraform privilege escalation detection.

## Quick Start
1. Configure `codexa.serverUrl` in Settings (default: `https://codexa-ye85.onrender.com`).
2. Open Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
3. Type `Codexa: Run Deep AST Security Scan`.
