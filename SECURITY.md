# Security Policy

## Reporting Security Vulnerabilities

We take the security of Codexa seriously. If you discover a vulnerability or security defect, please report it privately rather than creating a public GitHub issue.

### How to Report
- Submit a report privately via [GitHub Security Advisories](https://github.com/Codewithjainam7/Codexa/security/advisories/new).
- Include clear reproduction steps, proof-of-concept snippets, and affected versions.

### Response & Remediation Timelines
- **Initial Acknowledgment**: Within **48 hours** of receiving the report.
- **Severity & Triage Assessment**: Completed within **7 days**.
- **Fix & Patch Release**: Targeted release within **90 days** (critical security issues prioritized within 14 days).

### Scope
- Core static AST rule engine and analysis pipelines.
- Ingestion services (ZIP decompressor, GitHub clone/archive fetching).
- REST API security, authentication filters, and rate limiters.
- Web & mobile frontend interfaces.
