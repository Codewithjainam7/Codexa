# ADR-0007: Resilient AI Model Cascade & Offline Circuit Breaker

## Status
**Accepted** (2026-09-07)

## Context & Problem Statement
Integrating Large Language Models into static code analysis introduces external network dependencies with unpredictable latency (1s to 30s+), frequent rate limits (HTTP 429), and third-party API outages. 

In mission-critical enterprise CI/CD pipelines, security gates must evaluate code deterministically in seconds. A developer's pull request must **never** be blocked or delayed because an external AI vendor is experiencing a DDoS attack or quota exhaustion.

## Decision Drivers
- **Zero-Blocking CI/CD Gating**: Security analysis must complete reliably even during complete third-party cloud outages.
- **Strict Latency Bounds**: External inference calls must never exceed a 15-second total timeout.
- **Graceful Degradation**: Users should receive high-quality deterministic remediation advice even when offline.

## Considered Options
1. **Hard Failure on AI Error**: Reject or fail the scan if AI calls fail. Discarded as unacceptable for CI/CD reliability.
2. **Synchronous Single-Model Retry**: Retry the same model up to 5 times. Discarded because upstream outages cause massive queue backpressure and build timeouts.
3. **Multi-Tier Cascade with Circuit Breaker & Deterministic Offline Fallback**: OpenRouter multi-model cascade (Claude 3.5 -> GPT-4o -> DeepSeek) coupled with a fast circuit breaker that immediately diverts to offline deterministic template rules upon failure.

## Decision Outcome
Chosen option: **Multi-Tier Cascade with Circuit Breaker & Offline Deterministic Fallback Engine**.

### Architecture Invariants:
- **Connection & Read Timeouts**: Connect timeout bounded to $3,000\text{ ms}$; read timeout bounded to $12,000\text{ ms}$.
- **Circuit Breaker Policy**: If failure rate exceeds $50\%$ over a sliding window of 10 requests, circuit transitions to `OPEN` for 60 seconds.
- **Immediate Offline Degradation**: When the circuit is `OPEN`, all remediation requests are instantly resolved ($< 0.05\text{ ms}$) via parameterized AST rewrite templates without initiating any outbound network connections.
- **Air-Gapped Mode**: When `CODEXA_AI_ENABLED=false` or no API key is supplied, the pipeline operates 100% offline seamlessly.

## Consequences
- **Positive**: 100% scan completion rate guaranteed across all network conditions.
- **Positive**: Zero latency spikes in CI/CD pull request gating checks.
- **Positive**: Air-gapped enterprise deployments operate with full static analysis capabilities.
- **Neutral**: Remediations generated by offline templates are parameterized patterns rather than customized natural-language prose.
