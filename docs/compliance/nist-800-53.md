# NIST SP 800-53 Rev. 5 Technical Controls Mapping Matrix

This document provides a comprehensive cross-reference mapping of **Codexa** static analysis and infrastructure-as-code security rules against the **National Institute of Standards and Technology (NIST) SP 800-53 Rev. 5** Security and Privacy Controls for Federal Information Systems.

---

## 1. Core Technical Controls Mapping

| NIST Control Family | Control ID | Control Name | Codexa Rule Mapping | Severity |
| :--- | :--- | :--- | :--- | :--- |
| **Access Control (AC)** | `AC-3` | Access Enforcement | `CR-AUTH-001`, `CR-RLS-001`, `CR-RSC-001`, `CR-PARAM-002` | `CRITICAL` / `HIGH` |
| | `AC-6` | Least Privilege | `CR-IAC-007` (IAM Wildcard), `CR-IAC-001` (Docker Root), `CR-K8S-001` (hostPath) | `CRITICAL` |
| | `AC-17` | Remote Access | `CR-WEBSOCKET-001` (CSWSH), `CR-CONFIG-001` (CORS Wildcard) | `HIGH` |
| **Identification & Authentication (IA)** | `IA-2` | Identification and Authentication | `CR-SECRET-001`, `CR-SECRET-002`, `CR-JWT-001` | `CRITICAL` |
| | `IA-5` | Authenticator Management | `CR-PASS-001`, `CR-SEC-013`, `CR-HELM-001` | `HIGH` |
| **System and Communications Protection (SC)** | `SC-8` | Transmission Confidentiality and Integrity | `CR-GRPC-001`, `CR-SEC-010`, `CR-CRYPTO-002` | `HIGH` |
| | `SC-12` | Cryptographic Key Establishment and Management | `CR-CRYPTO-001`, `CR-CRYPTO-002`, `CR-RAND-001` | `HIGH` |
| | `SC-28` | Protection of Information at Rest | `CR-IAC-006` (Unencrypted Volumes), `CR-IAC-008` (S3 Exposure) | `CRITICAL` |
| **System and Information Integrity (SI)** | `SI-10` | Information Input Validation | `CR-SQL-001`, `CR-CMD-001`, `CR-XXE-001`, `CR-SSTI-001`, `CR-NOSQL-001`, `CR-REDOS-001` | `CRITICAL` / `HIGH` |
| | `SI-11` | Error Handling | `CR-QUAL-006` (Empty Catch), `CR-OPS-001` | `MEDIUM` |
| **Supply Chain Risk Management (SR)** | `SR-3` | Supply Chain Controls and Processes | `CR-DEP-001`, `CR-SUPPLY-001` (Dependency Confusion) | `HIGH` |

## 2. Federal Compliance Export

Codexa audit reports can be rendered directly into machine-readable format for FedRAMP / FISMA System Security Plans (SSP) and Plan of Action and Milestones (POA&M):
```bash
codexa scan . --format sarif --output nist-sp800-53-audit.sarif
```
