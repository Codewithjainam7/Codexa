# Changelog & Version History 📋

All notable changes to the Codexa Code Security & Production Readiness Platform are documented in this file.

## [1.2.0] - 2026-09-18

### 🚀 Added & Enhanced
- **Universal Multi-Encoding & BOM Auto-Detection Engine**:
  - Implemented `readFileLines()` in `UniversalMultiLanguageRule` with byte-level header inspection.
  - Automatic detection and lossless decoding of **UTF-16LE** (`0xFF 0xFE`) and **UTF-16BE** (`0xFE 0xFF`) files generated by Windows PowerShell redirection (`>`) and database export tools.
  - Support for **UTF-8 BOM** (`0xEF 0xBB 0xBF`) and automatic elimination of lingering null bytes (`\0`) preventing regex matching failures.
- **`CR-RLS-001` (Insecure Row-Level Security Policy)**:
  - Detects administrative SQL scripts that bypass database security by granting unconditional anonymous access (`CREATE POLICY "Allow anon access" ... USING (true)`).
- **`CR-SEC-002` (Fallback Secret & Token Extraction)**:
  - Enhanced pattern matching to detect fallback credentials across logical OR (`||`) and nullish coalescing (`??`) assignments:
    `process.env.MAILTRAP_API_TOKEN || '...'` and `process.env.MAILTRAP_INBOX_ID || '...'`.
- **`CR-ARCH-001` (Dev Middleware Production Trap)**:
  - Identifies development server middleware route declarations (e.g., `configureServer(server) { server.middlewares.use('/api/email') }` in `vite.config.ts`), warning teams of 404 traps in production deployments.
- **`CR-SEC-007` (Predictable Access PINs & Timestamp Auth Tokens)**:
  - Identifies insecure 4-digit visitor PINs generated with `Math.random()` (e.g., `Math.floor(1000 + Math.random() * 9000)`).
  - Identifies predictable magic link and session tokens constructed with `Date.now()` (e.g., `tok_${schemeId}_${Date.now()}`).
- **`CR-EDGE-001` (Unauthenticated Edge Function Relay)**:
  - Implemented `REAL_EDGE_AUTH_PATTERN` to verify functional caller authentication (`req.headers.get('authorization')` or `supabase.auth.getUser()`).
  - Successfully resolves false negatives caused by decorative CORS headers (`'Access-Control-Allow-Headers': 'authorization'`).
- **Test Suite Expansion**:
  - Expanded backend regression test suite to **114 passing unit, integration, and security tests** (100% pass rate).

## [1.1.0] - 2026-09-14

### 🚀 Added & Enhanced
- **High-Scale Ingestion Boundaries**:
  - Expanded maximum archive upload limit from 500 MB to **3.0 GB (3,072 MB)**.
  - Increased file processing quota to **50,000 files** per repository scan.
  - Increased staging disk quota to **4,000 MB**.
- **High-Throughput Streaming Extraction**:
  - Upgraded decompression buffer size from 8 KB to **64 KB**, resulting in an **8.2x speedup** (up to 815 MB/s extraction throughput).
- **GitHub Ingestion Enhancements**:
  - Added support for optional `GITHUB_TOKEN` authorization headers to avoid API rate limits during large repository scans.
- **OASIS SARIF v2.1.0 Exporter**:
  - Added direct SARIF v2.1.0 JSON report export endpoint (`/api/v1/analyses/{jobId}/report?format=sarif`) for native GitHub Advanced Security Code Scanning integration.
- **Architectural & Maintainability Metrics**:
  - Added dedicated Maintainability Index ($0–100$) and Architectural Health ($0–100$) metrics persisted in database entities and displayed across UI cards.

## [1.0.0] - 2026-09-11

- **Dual-Spectrum Static Analysis Engine**:
  - White-Box AST Code Audit: McCabe Cyclomatic Complexity, Nesting Depth, Monolithic Methods, Top Complex Files Leaderboard.
  - Black-Box Attack Surface Scanner: Automated HTTP route discovery, Ingress parameter mapping, Access control boundary checks.
- **30 Deterministic AST Static Rules**:
  - Security rules: `CR-SQL-001`, `CR-CMD-001`, `CR-SEC-001` through `CR-SEC-010`, `CR-AUTH-001`, `CR-XSS-001`, `CR-PASS-001`, `CR-CRYPTO-001`, `CR-CONFIG-001`.
  - Quality rules: `CR-QUAL-001` through `CR-QUAL-006`.
  - Operations rules: `CR-OPS-001` through `CR-OPS-004`.
  - Performance rules: `CR-PERF-001`.
- **Explainable Readiness Scoring Engine**:
  - 5-Dimension readiness score calculation with Hard Verdict Overrides (`NOT_READY`, `NEEDS_URGENT_FIXES`, `REVIEW_COMPLETE`).
- **AI & Deterministic Remediation Engine**:
  - NVIDIA Nemotron LLM via OpenRouter with zero-cost deterministic offline fallback.
  - In-flight high-entropy secret masking.
- **Interactive 5-Tab Dashboard**:
  - React 18 + Vite 5 + TailwindCSS dark-mode interface.
  - Interactive repository file tree explorer with finding density badges.
  - Side-by-side git-style diffs and 1-click patch copy.
- **Multi-Format Export Engine**:

- **Cross-Platform Mobile Support**:
